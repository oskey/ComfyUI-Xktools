# ComfyUI-Xktools

一个用于ComfyUI的中文到英文提示词翻译插件，使用百度翻译API实现高质量的中文提示词翻译。

## 功能特性

- 🌏 **中文转英文翻译**：将中文提示词翻译为英文，方便在各种AI绘画模型中使用
- 🔄 **批量翻译**：支持一次性翻译多个提示词
- 🎯 **集成CLIP编码器**：新增中文CLIP文本编码器，直接输出条件给采样器
- 🔧 **简单配置**：只需配置百度翻译API的APP ID和密钥即可使用
- ⚡ **实时翻译**：快速响应，支持自动翻译和手动翻译模式
- 🛡️ **错误处理**：完善的错误提示和异常处理机制
- 💾 **配置保存**：支持保存API配置，避免重复输入

## 节点介绍

### 1. 中文转英文翻译器
- **功能**：将中文文本翻译为英文
- **输出**：翻译后的英文文本
- **适用场景**：需要单独获取翻译结果的情况

### 2. 中文CLIP文本编码器 ⭐ 推荐
- **功能**：集成翻译和CLIP编码，直接输出条件
- **特点**：
  - 左侧连接CLIP加载器
  - 右侧直接输出CONDITIONING给采样器
  - 节点底部显示翻译结果预览
  - 支持自动翻译开关控制
- **适用场景**：直接用于图像生成流程

### 3. 批量中文转英文翻译器
- **功能**：批量翻译多个中文提示词
- **输出**：用分隔符连接的英文文本
- **适用场景**：需要处理多个提示词的情况

2. 重启ComfyUI

## 百度翻译API申请教程

### 1. 注册百度开发者账号
- 访问 [百度翻译开放平台](https://fanyi-api.baidu.com/)
- 点击"立即使用"或"开发者中心"
- 使用百度账号登录（没有账号需要先注册）

### 2. 实名认证
- 登录后进入开发者中心
- 完成个人实名认证（企业用户需要企业认证）
- 认证通过后才能申请API

### 3. 创建应用
- 在开发者中心点击"管理控制台"
- 选择"通用翻译API"
- 点击"立即开通"
- 填写应用信息：
  - **应用名称**：自定义名称，如"ComfyUI翻译插件"
  - **应用简介**：简单描述应用用途
  - **应用类型**：选择"API"
  - **应用领域**：选择"其他"

### 4. 获取API密钥
- 应用创建成功后，在应用列表中找到你的应用
- 点击应用名称进入详情页
- 在"基本信息"中可以看到：
  - **APP ID**：应用的唯一标识
  - **密钥**：用于API调用的密钥

### 5. 费用说明
- 百度翻译API提供免费额度：**每月200万字符**
- 超出免费额度后按量计费：**49元/百万字符**
- 对于个人用户的日常使用，免费额度通常足够

## 使用方法

### 1. 中文CLIP文本编码器（推荐）
1. 在ComfyUI中添加节点：`Xktools/翻译/中文CLIP文本编码器`
2. 连接CLIP加载器到左侧的clip输入
3. 配置参数：
   - **chinese_text**：输入要翻译的中文提示词
   - **auto_translate**：是否自动翻译（勾选=翻译为英文，不勾选=直接使用中文）
   - **app_id**：填入百度翻译API的APP ID
   - **secret_key**：填入百度翻译API的密钥
   - **save_config**：是否保存配置到文件
4. 右侧的conditioning输出直接连接到采样器
5. 节点底部会显示翻译结果预览

### 2. 单个翻译节点
1. 在ComfyUI中添加节点：`Xktools/翻译/中文转英文翻译器`
2. 配置参数：
   - **chinese_text**：输入要翻译的中文提示词
   - **app_id**：填入百度翻译API的APP ID
   - **app_key**：填入百度翻译API的密钥
   - **auto_translate**：是否自动翻译（默认开启）

### 3. 批量翻译节点
1. 在ComfyUI中添加节点：`Xktools/翻译/批量中文转英文翻译器`
2. 配置参数：
   - **chinese_texts**：每行输入一个中文提示词
   - **app_id**：填入百度翻译API的APP ID
   - **app_key**：填入百度翻译API的密钥
   - **separator**：翻译结果的分隔符（默认为", "）

## 常见问题

### Q: 提示"APP ID或密钥错误"怎么办？
A: 请检查：
- APP ID和密钥是否正确复制（注意不要有多余的空格）
- 是否已完成实名认证
- 应用是否已经审核通过

### Q: 提示"访问频率受限"怎么办？
A: 百度翻译API有QPS限制：
- 标准版：10 QPS
- 高级版：100 QPS
- 如果频繁调用，请适当降低调用频率

### Q: 翻译质量不理想怎么办？
A: 建议：
- 使用标准的中文表达，避免网络用语或方言
- 提示词尽量简洁明了
- 可以手动调整翻译结果

### Q: 中文CLIP编码器的自动翻译开关有什么用？
A: 
- **勾选自动翻译**：中文 → 翻译为英文 → 英文进行CLIP编码
- **不勾选自动翻译**：直接用中文进行CLIP编码
- 适用于支持中文的模型或需要保持原文的场景

### Q: 如何查看API使用量？
A: 在百度翻译开放平台的管理控制台中可以查看：
- 当月使用量
- 剩余免费额度
- 调用统计
